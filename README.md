# Dumble (v2.5)

## Introduction
Dumble is a Puppeteer-based script that runs in a Node.js environment through CMD for only for testing purposes and your privately owned exam suite's security testing.

## Supported Devices
Desktop PCs or Laptops running **Windows 10 or newer** are supported. Note: this tool might not work accordingly on all devices.
Fixes: 
- Use --verbose mode
- Update node.js and git
- Fix vulnerabilities in puppeteer via node.js 

## Requirements

- [Node.js (v16 or later recommended)](https://nodejs.org/en/download)

- [Git](https://git-scm.com/downloads)

- Administrator privileges for the machine you prefer installing this tool to


## Installation (cmd)

**1. Clone the repository:**

<pre>git clone https://github.com/bunsybuns123/dumble.git</pre>


<pre>cd dumble</pre>

**2. Install the required packages:**

<pre>npm install puppeteer puppeteer-extra puppeteer-extra-plugin-stealth</pre>


## Usage

**<pre>Usage:**
node dumble [args]


**Arguments:**
        --verbose    Verbose output
</pre>
